# RankProbe 0.1.0a5

评测分数变了，先看看是不是比较条件也变了。这版让你直接接入自己的 CSV、JSONL 或 TREC 文件，从发现卡片找到证据，再按提示检查导出或评测条件。

Check whether a changed ranking score comes from ranking changes, ties, duplicated candidates or a different evaluation pool. This alpha brings real-file onboarding, direct evidence navigation and encoding-error recovery into the independent repository's distribution.

## 下载哪一个 / Which download?

- **`RankProbe-0.1.0a5.zip`**：推荐首次使用。含离线 wheel、源码、原创示例和开始说明，完整解压后读 `START_HERE.md`。Recommended complete offline bundle.
- `rankprobe-0.1.0a5-py3-none-any.whl`：已有 Python 3.10+ 独立环境时安装。Installable core, with no runtime dependencies.
- `rankprobe-0.1.0a5.tar.gz`：源码分发包。Source distribution.
- `RELEASE_INFO.json`、`SHA256SUMS`：公开源码提交、资产大小与 SHA-256。Source/asset receipt and checksums.

Windows 核对 ZIP：在下载目录运行 `(Get-FileHash .\RankProbe-0.1.0a5.zip -Algorithm SHA256).Hash`，与 `SHA256SUMS` 同名条目比较，大小写不影响十六进制值。完整 ZIP 内另有逐文件清单。Read `source/docs/source-recovery.md` before rerunning an older report.

## 这版包含什么 / Included changes

- 免安装入口可读取自己的文件，也能比较两次导出；成功生成的报告会给出实际路径。
- 发现卡片可展开证据并跳转到对应 run 或比较，不必在长报告里来回找。
- 非 UTF-8 输入会解释如何从原来源另存并重试；不猜编码、不丢行、不替换坏字节。
- 完整下载绑定公开源码提交，说明如何保留输入、旧报告与对应代码。

Core metric calculations and missing-label rules are unchanged from the reviewed source. Missing judgments stay unknown; an unavailable value is not zero. Reports diagnose exported evaluation conditions and do not certify model quality, complete retrieval, leakage absence or independent adoption.

This is an **alpha prerelease**, not a stable release or a claim of measured real-user benefit. The earlier alpha-4 release in the course repository remains unchanged. PyPI and cloud deployment are outside this release.
