# RankProbe 0.1.0a9

MTEB 预测文件转换失败时，先找到需要检查的那条记录。这版把报错位置写清楚：哪个文件、哪个 subset/split，以及哪个查询和文档。按这个位置回到原始导出核查，再用新文件重试。

## 下载和使用

- **`RankProbe-0.1.0a9.zip`**：推荐首次使用，含离线 wheel、对应源码、示例和 `START_HERE.md`。
- `rankprobe-0.1.0a9-py3-none-any.whl`：Python 3.10+ 的可安装核心。
- `rankprobe-0.1.0a9.tar.gz`：源码分发包，含本次更新的 MTEB 转换说明。
- `RELEASE_INFO.json` 与 `SHA256SUMS`：核对源码提交和文件摘要。旧版和旧报告请单独保留。

## 转换失败后怎么继续

按 [MTEB 接入步骤](https://github.com/C4LLM3LUC4S/rankprobe/blob/v0.1.0a9/docs/mteb-workflow.md)检查报错中的原始记录，保留原文件，从源程序另存一份。新的 CSV 路径和报告目录都要明确指定，只有转换成功才启动审计。报错包含本地路径和编号，分享前先检查内容。

缺失标签继续是未知；本来相同的分数可以保留，不能为了清掉警告而编造标签或分数。报告能帮助核查导出和评测条件，不能认证模型质量。

本次更新的是随包源码中的转换说明和恢复检查。核心解析、排序、指标和报告数据的含义没有改变；没有增加模型推理或自动修复。仍是 **alpha 预发行**，开发者小样例验证不代表独立用户采用或人工节时。所有旧发行保持原样。

## English

The local MTEB conversion recipe now identifies an invalid score or ID by source file, selected subset/split and query/document pair, followed by the original validation error. Inspect that export entry and retry with a fresh source, CSV destination and report folder. Complete selected-scope validation still occurs before exclusive CSV creation; require conversion success before auditing.

Use the complete bundle for the reviewed source recipe, or its source distribution with the installed core. The wheel's numerical behavior is unchanged. Preserve original files, valid values, IDs, order, genuine ties and unknown judgments. Keep the matching source and checksums. This GitHub **alpha prerelease** does not claim automatic data repair, model-quality certification, independent adoption, PyPI or cloud deployment.
