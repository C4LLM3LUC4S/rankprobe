# RankProbe 0.1.0a8

CSV 提示“缺少列”，不一定是数据真的没有这些字段。这版会提醒你检查英文逗号和准确列名，再回到原始程序另存一份文件，减少来回猜格式的成本。

## 下载和使用

- **`RankProbe-0.1.0a8.zip`**：推荐首次使用，包含离线安装包、对应源码、示例和 `START_HERE.md`。
- `rankprobe-0.1.0a8-py3-none-any.whl`：安装到 Python 3.10+ 独立环境。
- `rankprobe-0.1.0a8.tar.gz`：源码分发包。
- `RELEASE_INFO.json` 与 `SHA256SUMS`：核对准确源码提交和文件摘要。旧版本请单独保留。

## 遇到缺列时怎么做

CSV 需要用英文逗号分隔，并使用 `query_id,item_id,score` 等规定列名。把 Tab 分隔文件改成 `.csv` 后缀不会改变内容。程序会继续拒绝原来不符合要求的文件，不自动猜分隔符、改列名或补值。

从原始来源另存新 CSV，再核对编号拼写、分数、全部已有标签、未知标签和行顺序。原文件先留着。合法引号字段里的 Tab 和分号仍是字段内容。详细步骤见 [CSV 表头恢复](../input-format.md#csv-header-errors)。

这版没有改变排序、指标、未知标签或报告 JSON 的含义。保存位置检查和旧报告备份恢复继续保留；已有报告请用新目录复核。恢复验证采用原创小样例，不是外部采用或人工收益证明。

## English

Missing-column CSV errors now explain comma separators, exact field names and a fresh export from the original producer. Keep original files, identifiers, numeric values, all supplied judgments, unknown labels and row order. The parser still rejects the original invalid input; it does not guess a delimiter or rename fields. Valid quoted tabs remain field content.

Use the complete `RankProbe-0.1.0a8.zip`, check `SHA256SUMS`, and keep its matching source. Parsing rules, ranking metrics and report data are unchanged. Earlier releases and report-backup recovery remain available. This is an **alpha prerelease** on GitHub, not a stable-version, PyPI or cloud release.
