# RankProbe 0.1.0a6

这版写报告时少占一份额外内存；写入出错时，原报告仍会保留。输入和指标规则不变。用自己的导出生成报告后，按发现中的证据回到原始文件核查，再保留原记录、使用新目录复核。

This maintenance alpha uses less extra memory while writing reports and preserves existing reports if writing fails. Input and metric rules are unchanged. It retains the real-file launcher, evidence navigation and encoding recovery from alpha-5.

## 下载哪一个 / Which download?

- **`RankProbe-0.1.0a6.zip`**：推荐首次使用。含离线 wheel、对应源码、原创示例和开始说明；完整解压后读 `START_HERE.md`。Recommended complete offline bundle.
- `rankprobe-0.1.0a6-py3-none-any.whl`：已有 Python 3.10+ 独立环境时安装。Dependency-free installable core.
- `rankprobe-0.1.0a6.tar.gz`：源码分发包。Source distribution.
- `RELEASE_INFO.json`、`SHA256SUMS`：公开源码提交、资产大小和 SHA-256。Source/asset receipt and checksums.

Windows 核对 ZIP：在下载目录运行 `(Get-FileHash .\RankProbe-0.1.0a6.zip -Algorithm SHA256).Hash`，与 `SHA256SUMS` 同名条目比较。完整 ZIP 内的 `BUILD_INFO.json` 记录对应公开源码提交，`MANIFEST.json` 覆盖其余成员。Keep the complete extracted folder; see [source and report recovery](../source-recovery.md).

## 这版修复什么 / Included changes

- JSON 报告逐段写入暂存文件，避免额外保留整份序列化文本；完整记录、输出字节和报告替换保护保持一致。解析和比较仍在内存中处理，不能据此承诺任意规模输入。
- [任务验收和工作量说明](../reliability.md)连接“问题、证据、行动、复核”，说明本地负载及两两比较数量增长。问题反馈表只收集大致工作量与任务，不要求上传私有导出。
- 默认下载、安装命令和发布入口统一指向 alpha-6；旧版源码、发行说明和资产各自保留。

JSON is written incrementally to the staging file rather than retaining another complete serialized report. Parsing and comparison still hold data in memory. Metric calculations, unknown-label rules, input preservation and report replacement behavior are unchanged.

## 怎样验收 / What to recheck

Use the original [TREC walkthrough](../../examples/trec/README.md): inspect `query_coverage_mismatch`, verify `q2` against the retained source rows, then compare the authored complete control in a new report directory. Preserve the earlier inputs and report. Check query/candidate scope, source hashes, unknown and assumed counts, metric eligibility and same-pool deltas; a warning disappearing alone does not establish model improvement.

The fixtures are invented software controls. They do not establish recovery of an actual model export, independent adoption or human time saved. Missing judgments remain unknown and an unavailable value is not zero. Reports do not certify model quality or complete evaluation correctness.

This is an **alpha prerelease**. The independent repository's [alpha-5 release](https://github.com/C4LLM3LUC4S/rankprobe/releases/tag/v0.1.0a5) and the course repository's alpha-4 release remain unchanged. PyPI and cloud deployment are outside this release.
